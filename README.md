# 📕 小红书自动回复助手

一个基于 Python + Selenium 的小红书自动化工具，可以自动搜索笔记、查看评论、智能回复，帮助您提升运营效率。

---

## ✨ 功能特性

- 🔍 **关键词搜索**：根据关键词自动搜索小红书笔记
- 💬 **评论抓取**：自动获取笔记下的所有评论
- 🤖 **智能回复**：支持自定义回复模板，自动回复评论
- 🎯 **关键词过滤**：可设置只回复包含特定关键词的评论
- 🖥️ **可视化界面**：提供美观的 Web 操作界面
- ⚙️ **灵活配置**：支持多种运行模式和参数配置

## 📖 使用指南

### 操作流程

程序操作分为 4 个步骤，界面顶部会显示当前进度：

```
[1.启动浏览器] → [2.登录账号] → [3.搜索笔记] → [4.自动回复]
```

---

### 详细操作步骤

#### 步骤 1：启动浏览器

1. **选择运行模式**：
   - **正常模式**：可以看到浏览器的所有操作，适合调试和首次使用
   - **无头模式**：浏览器在后台运行，不显示界面，节省资源

2. **点击「🚀 启动浏览器」按钮**

   程序会自动下载 Chrome 驱动（首次使用可能需要等待几秒钟），然后打开小红书官网。

> ⚠️ **注意**：如果遇到驱动下载失败，可以手动下载对应版本的 ChromeDriver。

---

#### 步骤 2：登录小红书账号

1. **在打开的浏览器中登录**

   浏览器会自动打开小红书首页，您需要：
   - 点击页面右上角的「登录」按钮
   - 选择登录方式（手机号验证码、微信扫码等）
   - 完成登录操作

2. **检查登录状态**

   登录完成后，回到 Web 界面，点击「🔍 检查登录状态」按钮：
   - ✅ **已登录**：状态变为绿色，可以继续下一步
   - ❌ **未登录**：状态为黄色，请在浏览器中完成登录

> 💡 **安全提示**：
> - 程序不会记录您的账号密码
> - 登录信息保存在浏览器本地，程序退出后会清除
> - 建议使用常用设备登录，避免触发风控

---

#### 步骤 3：搜索笔记

1. **输入搜索关键词**

   在「搜索关键词」输入框中输入您想要搜索的内容，例如：
   - `穿搭分享`
   - `美食探店`
   - `旅游攻略`
   - `护肤心得`

2. **点击「🔍 开始搜索」按钮**

   程序会自动在浏览器中执行搜索，完成后显示搜索结果列表。

3. **查看搜索结果**

   每条笔记会显示：
   - 笔记标题
   - 笔记 ID
   - 两个操作按钮：
     - **📋 查看评论**：选择该笔记，进入下一步操作
     - **🔗 打开链接**：在新窗口中打开原始笔记链接

---

#### 步骤 4：查看评论与自动回复

##### 4.1 获取评论

1. **选择笔记后**，界面会显示当前选中的笔记标题

2. **点击「📋 获取评论」按钮**

   程序会自动滚动页面加载所有评论，完成后显示：
   - **总评论数**：该笔记下的评论总数
   - **已回复数**：本次操作已回复的评论数
   - **待回复数**：尚未回复的评论数

3. **评论列表**

   每条评论会显示：
   - 评论者昵称
   - 评论内容
   - 点赞数

##### 4.2 配置自动回复

在开始自动回复前，您可以配置以下参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| **回复模板** | 自动回复的内容格式 | 感谢您的留言！{author} |
| **关键词过滤** | 只回复包含特定关键词的评论 | 多少钱,价格,怎么买 |
| **最大回复数量** | 每次最多回复的评论数 | 5 |

###### 回复模板变量说明

模板中可以使用以下变量：

- `{author}`：评论者的昵称
- `{content}`：评论的原始内容

**示例**：
```
模板：感谢 {author} 的留言！关于"{content}"，我来为您解答~

实际效果：感谢 小明同学 的留言！关于"请问这个多少钱？"，我来为您解答~
```

###### 关键词过滤说明

- 留空表示回复**所有评论**
- 多个关键词用**英文逗号**分隔
- 评论中**包含任意一个关键词**就会被回复

**示例**：
```
关键词：多少钱,价格,怎么买

匹配的评论：
- "请问这个多少钱？" ✅
- "这个价格是多少？" ✅
- "在哪里可以买？" ✅
- "请问好用吗？" ❌（不包含关键词）
```

##### 4.3 开始自动回复

1. **确认配置后**，点击「🤖 开始自动回复」按钮

2. **程序会自动执行以下操作**：
   - 逐条匹配符合条件的评论
   - 使用回复模板生成个性化回复
   - 点击「回复」按钮，输入内容，点击「发送」
   - 每条回复之间有随机延迟（2-4秒），模拟人工操作

3. **查看回复结果**

   回复完成后会显示详细的回复结果，包括：
   - 评论者昵称
   - 原始评论内容
   - 发送的回复内容
   - 回复状态（成功/失败）

## ⚙️ 高级配置

### 环境变量配置

可以在项目根目录创建 `.env` 文件来自定义配置：

```env
# Flask 配置
SECRET_KEY=your-secret-key-here

# Selenium 配置
SELENIUM_HEADLESS=false
SELENIUM_WAIT_TIME=10

# 回复配置
MAX_REPLIES_PER_NOTE=5
MIN_DELAY_BETWEEN_REPLIES=2.0
MAX_DELAY_BETWEEN_REPLIES=4.0

# 默认回复模板
DEFAULT_REPLY_TEMPLATE=感谢您的留言！{author}，关于"{content}"的问题，我会尽快回复您的~
```

### 配置参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `SELENIUM_HEADLESS` | bool | false | 是否使用无头模式 |
| `SELENIUM_WAIT_TIME` | int | 10 | 页面元素等待超时时间（秒） |
| `MAX_REPLIES_PER_NOTE` | int | 5 | 每次最大回复数量 |
| `MIN_DELAY_BETWEEN_REPLIES` | float | 2.0 | 回复间隔最小延迟（秒） |
| `MAX_DELAY_BETWEEN_REPLIES` | float | 4.0 | 回复间隔最大延迟（秒） |

## ⚠️ 注意事项

### 使用限制

1. **频率限制**
   - 小红书有严格的操作频率限制
   - 建议每次回复不超过 10 条
   - 两次操作之间间隔至少 5 分钟

2. **登录限制**
   - 首次登录可能需要短信验证或人脸验证
   - 异地登录可能触发风控，建议使用常用设备
   - 登录状态保持时间有限，长时间不操作需要重新登录

3. **内容限制**
   - 回复内容不能包含违规词汇
   - 不能发送广告、营销类内容
   - 避免重复发送相同内容

## 🛠️ 常见问题

### Q1: 启动浏览器失败怎么办？

**可能原因及解决方案**：

1. **Chrome 浏览器未安装**
   - 解决方案：安装最新版 Chrome 浏览器

2. **Chrome 版本与驱动不匹配**
   - 解决方案：webdriver-manager 会自动下载对应版本
   - 手动解决：查看 Chrome 版本（设置 → 关于 Chrome），手动下载对应 ChromeDriver

3. **权限问题**
   - Windows：以管理员身份运行命令行
   - macOS：在系统设置中允许终端控制电脑

### Q2: 搜索不到笔记怎么办？

**可能原因**：

1. **关键词太冷门**
   - 解决方案：尝试更热门的关键词

2. **页面加载缓慢**
   - 解决方案：增加 `SELENIUM_WAIT_TIME` 配置值

3. **小红书页面改版**
   - 解决方案：检查页面元素是否变化，可能需要更新代码

### Q3: 评论加载不全怎么办？

**解决方案**：

1. 程序会自动滚动页面加载评论
2. 如仍有遗漏，可以手动在浏览器中滚动到底部
3. 然后重新点击「获取评论」按钮

### Q4: 自动回复失败怎么办？

**常见原因**：

1. **评论需要二级密码**
   - 现象：点击回复后弹出密码输入框
   - 解决方案：在浏览器中手动输入一次密码，选择「记住」

2. **评论已被删除**
   - 解决方案：程序会自动跳过已删除的评论

3. **内容包含敏感词**
   - 解决方案：修改回复模板，避免使用敏感词汇

4. **操作过于频繁**
   - 现象：发送失败，提示「操作频繁」
   - 解决方案：停止操作，等待一段时间后再试

### Q5: 登录后刷新页面需要重新登录？

**原因**：

- 每次启动浏览器都是全新的会话
- 登录信息不会持久保存

**解决方案**：

- 每次启动程序后都需要重新登录
- 这是安全设计，避免登录信息泄露

### Q6: 如何停止正在运行的回复任务？

**方法**：

1. 点击界面上的「⏹️ 取消回复」按钮（如果可见）
2. 或者直接关闭 Web 页面，刷新后重新开始
3. 紧急情况可以关闭浏览器窗口

## 🧩 模块说明

### xiaohongshu_bot.py

核心自动化模块，包含以下主要类和方法：

#### `XiaohongshuBot` 类

| 方法 | 说明 |
|------|------|
| `init_driver()` | 初始化 Chrome 浏览器驱动 |
| `open_xiaohongshu()` | 打开小红书官网 |
| `check_login_status()` | 检查当前登录状态 |
| `search_by_keyword(keyword)` | 根据关键词搜索笔记 |
| `get_note_comments(note_url)` | 获取指定笔记的评论 |
| `reply_comment(comment_element, text)` | 回复单条评论 |
| `auto_reply_comments()` | 自动回复多条评论 |
| `close()` | 关闭浏览器 |

### app.py

Flask Web 应用，提供 REST API 接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 首页，返回 Web 界面 |
| `/api/start_bot` | POST | 启动浏览器 |
| `/api/check_login` | GET | 检查登录状态 |
| `/api/search` | POST | 搜索笔记 |
| `/api/get_comments` | POST | 获取评论 |
| `/api/auto_reply` | POST | 启动自动回复任务 |
| `/api/task_status/<task_id>` | GET | 查询任务状态 |
| `/api/stop_bot` | POST | 关闭浏览器 |

## 🔧 自定义开发

### 添加新功能

如果需要扩展功能，可以：

1. **在 `xiaohongshu_bot.py` 中添加新方法**

   ```python
   def custom_function(self, param):
       # 自定义功能实现
       pass
   ```

2. **在 `app.py` 中添加对应的 API 接口**

   ```python
   @app.route('/api/custom', methods=['POST'])
   def custom_api():
       # 处理请求
       pass
   ```

3. **在 `templates/index.html` 中添加界面元素**

   ```html
   <div class="form-group">
       <label>自定义功能</label>
       <input type="text" id="custom-input">
       <button class="btn btn-primary" onclick="customFunction()">执行</button>
   </div>
   ```

### 修改界面样式

界面样式使用纯 CSS 实现，位于 `templates/index.html` 的 `<style>` 标签中：

- 修改 `:root` 中的 CSS 变量可以改变主题颜色
- 响应式布局使用 Flexbox 和 Grid
- 移动端适配在 `@media (max-width: 768px)` 中
